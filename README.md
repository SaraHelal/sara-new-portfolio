# Sara Helal — Portfolio prototype

React + TypeScript + Vite + Tailwind CSS. First working draft of the agreed editorial, sidebar-led portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. To create production files: `npm run build`.

## Before publishing

- **Replace the illustrated phone UI** in `src/App.tsx` (`ProjectPreview`) with an authentic Quran Revision screenshot. The current illustration is explicitly a *stylised preview*, not an actual screenshot.
- Review all English copy for accuracy and tone.
- Add your real CV download link only when the PDF is available.
- Add verified project links/screenshots for Journalist Website and Movie Explorer.
- Check accessibility and responsive behaviour on your own devices.

This is an initial prototype, not a final production release.
